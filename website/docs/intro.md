# Documentation Overview

Welcome to the robot.ai documentation. This platform provides comprehensive learning resources for humanoid robotics, covering ROS 2, simulation, AI, and multimodal systems.

## Learning Modules

The platform is organized into four core modules:

- **[Module 1: The Robotic Nervous System (ROS 2)](/modules/ros2)** - Middleware for robot control
- **[Module 2: The Digital Twin (Gazebo & Unity)](/modules/gazebo-unity)** - Physics simulation and environments
- **[Module 3: The AI-Robot Brain (NVIDIA Isaac)](/modules/nvidia-isaac)** - Perception and motion intelligence
- **[Module 4: Vision-Language-Action (VLA)](/modules/vla)** - Multimodal reasoning and behavior

For an interactive introduction, visit our [landing page](/) to explore the modules with detailed slides and examples.

If you're new to humanoid robotics, we recommend starting with the [Getting Started](./getting-started/installation.md) guide to set up your development environment.
